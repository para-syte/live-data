Market Data Tracker
-
**Overview**
-
Simple program to track data from the stock market.

**Tech used**

- C++
- libcurl
- TwelveData API
- nlohmann JSON parser

**Goals**

- live data streaming via websocket programming
- rolling data
- clean output via a tui
- more analytics
- better error handling

**DISCLAIMER**

This program has limited features and still under development.
